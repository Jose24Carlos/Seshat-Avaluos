#  Sistema de Gestión de Avalúos Inmobiliarios

##  Descripción
Este proyecto consiste en el desarrollo de un sistema web para la gestión de avalúos inmobiliarios, enfocado en digitalizar el proceso de solicitud, seguimiento y actualización de avalúos dentro de una organización.

El sistema permite la interacción entre dos tipos de usuarios:
* Cliente
* Arquitecto / Valuador

El proyecto está alojado en un servidor y utiliza una base de datos para almacenar la información de los usuarios y las solicitudes.

---

## Objetivo
Optimizar y digitalizar el proceso de avalúos inmobiliarios, proporcionando mayor control, trazabilidad y visibilidad tanto para el cliente como para el valuador.

---

##  Problema
El proceso tradicional de avalúos presenta las siguientes dificultades:
* Falta de seguimiento centralizado
* Baja visibilidad del estado del avalúo para el cliente
* Procesos manuales y poco estandarizados
* Dificultad para actualizar y consultar el progreso

---

##  Solución
Se desarrolló un sistema que permite:

* Registro y autenticación de usuarios
* Creación de solicitudes de avalúo
* Aprobación de solicitudes
* Inicio del proceso de valuación
* Actualización de estados por parte del arquitecto
* Consulta del avance por parte del cliente

---

##  Flujo del sistema
1. El cliente solicita un avalúo
2. El arquitecto revisa y aprueba la solicitud
3. El proceso de avalúo inicia
4. El arquitecto actualiza el estado
5. El cliente monitorea el progreso en tiempo real

---

## Tipos de Usuario

| Usuario            |                  Función                          | 
|--------------------|---------------------------------------------------|
| Cliente            | Solicita avalúos y consulta el estado             |
| Arquitecto         | Aprueba solicitudes y actualiza el proceso        |
